# Comandos

Todos los comandos de `dots`, con sus opciones. Es lo mismo que ves con
`dots <comando> --help`, aquí a mano para consultarlo.

| Comando | Qué hace |
| --- | --- |
| [`dots`](dots.md) | dotsmithy: la herrería de tus dotfiles |
| [`dots add`](add.md) | registra e instala uno o varios paquetes |
| [`dots completion`](completion.md) | genera el script de autocompletado para tu shell |
| [`dots completion bash`](completion-bash.md) | genera el script de autocompletado para bash |
| [`dots completion fish`](completion-fish.md) | genera el script de autocompletado para fish |
| [`dots completion powershell`](completion-powershell.md) | genera el script de autocompletado para powershell |
| [`dots completion zsh`](completion-zsh.md) | genera el script de autocompletado para zsh |
| [`dots externals`](externals.md) | trae y prepara los recursos externos declarados |
| [`dots init`](init.md) | arranca una máquina desde cero (perfil, contenido, estado, aplica) |
| [`dots link`](link.md) | despliega los dotfiles a $HOME (symlinks, modelo Stow) |
| [`dots status`](status.md) | enseña el perfil, las capas y el contenido de esta máquina (solo lectura) |
| [`dots sync`](sync.md) | informa de qué paquetes declarados faltan por instalar (solo lectura) |
| [`dots update`](update.md) | trae los cambios del contenido y los aplica |
